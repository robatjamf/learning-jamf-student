## Tools

### Day 1 — Context & Empathy

- **GitHub Desktop** — [desktop.github.com](https://desktop.github.com/) — Visual Git client for cloning repos and managing commits
- **Visual Studio Code** — [code.visualstudio.com](https://code.visualstudio.com/) — Code editor for viewing and editing workshop files
- **Git** — Included with macOS Command Line Tools or install via Homebrew — Version control for tracking changes
- **Homebrew** — [brew.sh](https://brew.sh/) — Package manager for installing developer tools on macOS
- **Apple Freeform** — Included with macOS — Whiteboard app for collaborative persona mapping

### Day 2 — Technical Foundations

- **VMware Fusion OR Virtual Buddy** — Virtual machine software (choose ONE, provided on USB sticks) — For running test macOS environments. Selection guidance: Virtual Buddy is lighter (~50 MB), VMware Fusion has more features (~500 MB). Choose based on disk space and familiarity.
- **macOS 15 + 26 IPSW** — macOS installer images (provided on USB sticks) — For creating test VMs
- **Claude Code** — [docs.anthropic.com/en/docs/claude-code](https://docs.anthropic.com/en/docs/claude-code/overview) — AI pair programming assistant (installed via curl)
- **Jamf Pro** — https://projsadp.jamfcloud.com — MDM platform for hands-on API practice
- **Jamf Pro Swagger UI** — https://projsadp.jamfcloud.com/api/doc — Interactive API documentation
- **curl** — Included with macOS — Command-line tool for making API requests
- **webhook.site** — [webhook.site](https://webhook.site/) — Free service for testing webhook payloads

### Day 3 — AI-Native Development

- **Claude Code** — Already installed on Day 2 — Used for compound engineering exercises

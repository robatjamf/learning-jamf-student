
# Day 1 Exercise: Your First Branch & Pull Request

## Instructions

1. **Create a branch** from `main` named `students/<your-name>` (e.g. `students/jane-doe`).

2. **Add a file** in this folder (`day-1/students/`) named `<your-name>.txt` — for example, `jane-doe.txt`.

3. **In your file**, include:
   - Your name
   - Your favorite animal (and why, if you want!)

   Example (`jane-doe.md`):
   ```
   # Jane Appleseed
   **Favorite animal:** Red Panda
   ```

4. **Commit and push** your branch with comment.

5. **Open a Pull Request** back into `main`.

💾 How do I save my work in Git?
git add .
Stage everything — get it ready to save
git commit -m "what I did"
Take the snapshot with a label
git push
Send it to GitHub
🔒 How do I get an API token?
TOKEN=$(curl -s -u "user:pass" -X POST ".../auth/token" | jq -r '.token')
Authenticate and save the token in one step
echo $TOKEN
Verify your token was saved
💻 How do I read data from Jamf? (GET)
curl -s -H "Authorization: Bearer $TOKEN" ".../computers-inventory" | jq .
GET request — list all computers, formatted with jq
✎️ How do I update data in Jamf? (PUT)
1YourName\'')"> curl -X PUT -H "Authorization: Bearer $TOKEN" -H "Content-Type: application/xml" ".../id/YOUR_ID" -d '<xml>'
PUT request — update an Extension Attribute on a device
🚀 How do I start a VM?
tart run my-vm
Boot the VM
tart ip my-vm
Get its IP address so you can connect to it
👀 How do I check what changed in my repo?
git status
See all changed/staged/untracked files
git log --oneline
See your commit history in a clean list
🤖 How do I ask Claude something from the terminal?
claude "your question here"
Ask anything — explain a command, debug an error, explain a concept
claude /init
Set up Claude in your project directory
🔒 How do I clean up when I'm done with an API session?
curl -X POST -H "Authorization: Bearer $TOKEN" ".../invalidate-token"
Kill your token — like logging out. Always do this!

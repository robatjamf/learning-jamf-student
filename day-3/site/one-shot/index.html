💻 Day 2 — Your Actual Takeaways

Tart VM Commands

Used tart list, tart run, and tart stop to create and manage a macOS virtual machine. The VM behaves like a real computer but runs on the resources of the main machine.

VM in Plain English

It's a virtual machine — a separate computer environment that runs inside your main computer, with its own OS, apps, and settings.

API Calls in Postman

Sent a POST request to get a bearer token, then used GET requests to retrieve device inventory from Jamf Pro. Responses came back as JSON data.

Push vs Pull

Pull — you ask the server for data when you need it. Push — the server automatically sends data when an event happens (like a webhook firing on device enrolment).

Webhook Payload

When the Jamf Pro webhook arrived, the payload was JSON containing the event type, device ID, device name, and timestamp — sent automatically to the endpoint.

💡 Key Concepts to Know

MDMManage many devices from one place — settings, apps, security rules.
DDMDeclarative Device Management — Apple's modern approach. Devices manage themselves against a declared state.
APISoftware talking to software. You send a request, you get data back.
RESTGET = read • POST = create • PUT = update • DELETE = remove
WebhookPush, not pull. The server tells YOU when something happens — like a doorbell.
VMA computer inside your computer. Isolated, resettable, throwaway.
Bearer TokenProve you logged in once, use the token everywhere else.
JSONStructured data both humans and machines can read: {"key": "value"}

📚 Glossary — Tap to Expand

Persona
A fictional character representing a real type of user — their workflow, tools, and pain points.
Four from Day 1: Enterprise IT Admin, K-12 IT Coordinator, Security Analyst, Help Desk Technician.
Journey Map
A walkthrough of a user's workflow — the steps, tools, and where they get stuck.
Like drawing a map of someone's commute, marking every traffic jam.
Virtual Machine (VM)
A computer running inside another computer with its own OS.
A snow globe — a little world inside your world. You can reset or throw it away without affecting anything outside.
Tart
A tool for running macOS VMs on Apple Silicon.
Key commands: tart clone • tart run • tart stop • tart ip
Polling vs. Pushing
Polling = you keep asking "anything new?" — Pushing = the system tells you when there's news.
Polling: "Are we there yet? Are we there yet?" — Pushing: "I'll tell you when we arrive."
Context Window
How much the AI agent can hold in memory at once. When full, earlier content gets dropped.
A whiteboard. You can keep writing, but eventually you run out of space and have to erase something.
Compounding
Distilling a full session — decisions, tradeoffs, dead ends — into a file the next session inherits.
A pilot's logbook. After every flight they record the route, decisions, turbulence. The next pilot starts with all that context.

⚙️ 7 Transferable Principles

1
Context Is Everything The quality of your output is determined by the quality of your context. AI only knows what you tell it.
2
Planning > Building 80% planning, 20% building. The plan IS the work. Execution is confirmation.
3
Share Your Mental Model The agent starts from zero. Transfer your picture of how things should work before it writes a line of code.
4
Recognise When to Quit Sunk cost is a trap. Starting fresh isn't failure — it's the skill.
5
It's a Conversation, Not a Command This is collaboration. Back-and-forth is where the real value comes from.
6
Review Against Your Plan Open the output. Use it. Your eyes and judgment are the primary review tool — not the AI's.
7
Compound Your Sessions Distill every session into a reference. The next session inherits everything you figured out instead of starting from zero.

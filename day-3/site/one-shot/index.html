Block 3 — Persona Mapping

Help Desk Technician

My group mapped the pain points of a Help Desk tech drowning in tickets:

  • 6 similar tickets with no way to batch-resolve them
  • iPad issue with no screenshot, no details
  • Multitasking across multiple open cases
  • 8 tickets resolved — 15 more arrive immediately
  • Missing Jamf Pro permissions to fix certain issues
If I Could Build One Thing

Smart Ticket Grouping

A tool that automatically groups tickets by device type and problem — so a technician can see patterns, batch similar issues, and clear the queue faster without context-switching constantly.

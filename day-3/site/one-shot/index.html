●  What we covered

Three days, three topics.

Each day built on the last — from git basics and APIs to automation to AI-native development.

Day 01

Git & Jamf Pro API

Branching, commits, and PRs — then straight into authenticating with tokens and querying real computer inventory from a live Jamf Pro instance.

API & Git
  • Created a personal branch and opened a pull request
  • Generated a bearer token via the Jamf Pro API
  • Queried computer inventory and read the JSON response
  • Invalidated tokens after use — proper API hygiene

Day 02

VMs, API & Webhooks

Spun up a Tart VM, created categories in Jamf via POST requests in Postman, then set up webhooks to fire automated responses to device events.

Automation
  • First time using a virtual machine — a computer inside a computer
  • Created a Jamf category using a POST request in Postman
  • Saw real API responses come back in the terminal
  • Configured a webhook to trigger on device events

Day 03

AI & Claude Code

Using Claude Code to build real things fast. Not just prompting — thinking in the Compound Engineering loop: Plan, Work, Review, Compound.

AI-Native Dev
  • First impression: Claude Code responds very quickly
  • Built two full sites — one-shot and planned builds
  • Learned Plan → Work → Review → Compound loop
  • Context is everything — the agent only knows what you give it

The VM Moment

The API Click

Sending a POST request and getting your own category back in the response. Making something exist in Jamf Pro via code — that's the moment it becomes real.

"Post and I got my category."

Hardest Thing

Presentations. Standing up and communicating what you built and why — harder than the tech itself. That's the skill people underestimate most.

The AI Shift

AI isn't magic and it isn't a threat — it's a tool. The better context you give it, the better it works. Compound Engineering changed how I think about building.

"Claude Code responds very quickly."

Biggest Shift in Thinking

Plan first, build second, review always — and carry the knowledge forward so the next session starts smarter than the last. The API transmits data from one place to another. AI is the same thing. You control what it does by what you give it. That's the whole game.

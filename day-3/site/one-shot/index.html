The Journey

3 Days in Review

1 Day

People, Context & What Is Jamf?

Started with icebreakers — drawing ducks with the group, tasting Dutch liquorice (zoet and zout), and hearing how a single bug led someone into tech. Shared how watching AI and robotics evolve sparked a curiosity about what else the field had to offer.

Learnt that Jamf is a mobile device management platform that helps organisations automate the deployment and configuration of Apple devices — not just enterprises, but schools too. Mapped the Enterprise IT Admin persona and realised how much manual work could be automated.

Jamf Pro Persona Mapping Git Basics Figma
2 Day

VMs, APIs & Webhooks

Spun up a Tart VM — a computer inside a computer, like a two-headed body sharing the same hardware but working independently. Used Postman to fire API requests at the Jamf Pro instance and created a category via a POST request.

APIs clicked as the "waiter" between the frontend and the backend. Webhooks are still a bit fuzzy — the idea of an event triggering a payload to a URL is clear, but want more hands-on practice.

3 Day

AI-Native Development

Working with Claude Code to build real things fast. The Compound Engineering Loop — Plan, Work, Review, Compound — gives structure to AI-assisted building so the output is actually intentional, not just generated.

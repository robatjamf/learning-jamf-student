Day 2
VMs, APIs & Webhooks
💻

Virtual Machines

Enrolled a Tart VM into a Jamf Pro instance via a configuration profile. Best analogy: "Your computer is a big house. Each VM is a smaller room with its own rules — its own little house inside."

🍳

APIs

Made a POST to create a new category. First attempt returned 401 Unauthorized — a missing bearer token. Fixed it and successfully created a computer category in Jamf Pro.

🔌

Webhooks

Webhooks fire automatically when an event occurs — no human request needed. The payload contained device data that looked opaque without knowing the device IDs.

✅

What Clicked

Virtual machines finally made complete sense after building one from scratch and enrolling it live.

Still Fuzzy

Webhooks vs. APIs feel clear in theory (webhooks are automatic; APIs need a request), but in practice during the live demo it was hard to tell them apart moment-to-moment. Something to revisit.

Git + Jamf Personas

Git Workflow

  1. Clone the repo — get a local copy
  2. Create a branch — your own workspace
  3. Make changes — edit files, add content
  4. Stage & commit — save a snapshot
  5. Push — upload your branch
  6. Open a PR — ask to merge into main

$ git add .
$ git commit -m "add my profile"

Webhooks

A URL that receives data when something happens. The server tells you — you don't have to keep asking.

"A doorbell. You don't check the door every 5 minutes."

Polling "Are we there yet?" repeated
Pushing "I'll tell you when we arrive"

Day 3

Compound Engineering

The 4-Step Loop

1
Plan
Define requirements. Surface unknowns. Share your mental model.
2
Work
Build with AI. Stay within the plan. Don't drift.
3
Review
Evaluate yourself first. Then ask Claude for gaps.
4
Compound
Distill decisions and reasoning into COMPOUND.md.
1
Context Is Everything
Quality of output = quality of context. The agent only knows what you tell it.
2
Planning > Building
80% plan, 20% execute. If you're mostly watching code get written, you skipped the hard part.
3
Share Your Mental Model
The agent starts from zero every time. Transfer your picture of the problem to it.
4
Recognize When to Quit
Sunk cost is a trap. "Let's start over — here's what I learned" is a skill.
5
It's a Conversation, Not a Command
You're collaborating, not delegating. Back-and-forth beats one-shot prompts.
6
Review Against Your Plan
Open the output. Use it. Your eyes come first, then ask Claude for gaps.
7
Compound Your Sessions
Distill reasoning, not just outcomes. CLAUDE.md stays lean; COMPOUND.md captures the full picture — decisions, tradeoffs, dead ends, and why. Every session inherits everything figured out before.

Jamf API (curl)

# Get token
TOKEN=$(curl -s -u "user:pass" \
-X POST ".../api/v1/auth/token" \
| jq -r '.token')
# Use token
curl -H "Authorization: Bearer $TOKEN" \
".../api/v1/computers-inventory"
# Invalidate
curl -X POST -H "Authorization: Bearer $TOKEN" \
".../api/v1/auth/invalidate-token"

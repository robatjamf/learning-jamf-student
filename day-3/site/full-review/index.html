Day 2

APIs, Virtual Machines & Automation

Virtual Machines — A Computer Inside a Computer

Ran brew update and upgrade. Learned about the mole command. The analogy: a VM is a mini-house built inside your main house — its own rooms, its own rules, same hardware.

API Bootcamp — The Restaurant Analogy

Made real API calls in Postman. Used POST requests to create categories on devices. You = customer, API = waiter, server = kitchen. Send an order, get data back.

Webhooks — Push vs Pull

Push: server sends data when an event fires. Pull: you ask for it when you need it. Received a live webhook payload — structured JSON showing what happened, when, and which resource was affected.

"When the webhook payload arrived, I was excited — it contained structured JSON data describing the event that triggered it."

— Naishe, After Block 4
Day 3

AI-Native Development with Claude Code

Two rounds of building the same page revealed everything about how to work with AI.

⚡

Round 1 — One-Shot

No context given. Got ocean blue colors. No Afro-beats. No green and beige. Technically fine — completely impersonal.

🎯

Round 2 — Planned Build

Gave AI everything: favorite colors, identity as an Afro-beats artist, layout preferences. The page came back as mine.

🔍

The Review Step

Switched from scrollable to per-section pages. The agent caught the color mismatch — ocean blue vs. the green and beige I actually felt.

"AI will use what we told it — and not use what we didn't."

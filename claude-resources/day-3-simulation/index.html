webhook-listener.py

from flask import Flask, request
import json
from datetime import datetime

app = Flask(__name__)

EVENTS_OF_INTEREST = [
    "ComputerEnrolled",
    "ComputerPolicyFinished",
    "ComputerCheckIn",
]

@app.route("/webhook", methods=["POST"])
def handle_webhook():
    event_type  = request.headers.get("X-Jamf-Event", "unknown")
    payload     = request.get_json(silent=True) or {}
    device_id   = payload.get("deviceId", "—")
    device_name = payload.get("deviceName", "—")

    if event_type in EVENTS_OF_INTEREST:
        ts = datetime.now().strftime("%H:%M:%S")
        print(f"[{ts}] {event_type}: {device_name} ({device_id})")

    return {"status": "received"}, 200

if __name__ == "__main__":
    print("Webhook listener running on :5000")
    app.run(host="0.0.0.0", port=5000, debug=True)

Self-Quiz

1. What is the biggest bottleneck in Maria's device journey, and approximately how long does it take?
The MDM enrollment step — approximately 4 hours per device when done manually. This is the step most automation-solvable with Jamf + ABM.
2. What HTTP header does Jamf use to identify the type of webhook event?
X-Jamf-Event — e.g. ComputerEnrolled, ComputerPolicyFinished, ComputerCheckIn
3. What file format do we use as the source image when creating a macOS VM in VMware Fusion or Virtual Buddy?
IPSW — a full macOS restore image. You create a new VM, point the app at the IPSW file, and it installs macOS automatically (takes 15–20 min).
4. What authentication method does the Jamf Pro API v1 use?
Bearer token — passed in the Authorization: Bearer $TOKEN header on every request.
5. What is the purpose of the Compound step in Compound Engineering?
To distill the full session — decisions made, tradeoffs, dead ends, review findings — into a persistent briefing (COMPOUND.md) so the next session starts with complete context instead of starting from zero.
6. What's the difference between polling an API and using a webhook?
Polling: you ask repeatedly "did anything happen?" — wastes requests. Webhook: the system calls you when something happens — event-driven, no wasted traffic.
7. What is the difference between a persona and a journey map?
A persona describes who the user is — their role, context, pain points, and goals. A journey map describes what they do — the sequence of steps they take to accomplish something. The persona is the who; the journey map is the what.
8. Why do journey maps matter for building automations?
They reveal where the time actually goes. A journey map makes the bottleneck visible — without it you'd guess at what to automate. Maria's map showed the enrollment step is 4 hours; that's where the automation value is concentrated.

Compound Engineering Loop

Plan
Define what you're building and why. Gather context. Resolve ambiguity. This is 80% of the work.
→
Work
Execute the plan with AI assistance. If the plan is solid, this step is fast.
→
Review
Open the output. Use it. Compare to intent. You evaluate first, then ask the agent to find gaps.
→
Compound
Distill the full session — decisions, tradeoffs, dead ends, findings — into a briefing for the next session.
↩ Loop repeats — each cycle starts smarter than the last
Planning is now the hard part Execution is trivial. The quality of your output = the quality of your context.
You are the reviewer The agent is your assistant, not your judge. Your eyes and judgment come first.
Compound ≠ notes Capture the reasoning, not just the outcome. "Why" is what makes the next session smarter.

## Quick Reference

- **20 students** → Use **4 Anthropic accounts** (5 students each)
- **Budget**: $30-50 for Sonnet
- **Risk moment**: Simultaneous "build" commands — stagger by 30 seconds between groups
- **Setup**: Create accounts with email aliases (e.g., `you+workshop-a@email.com`)

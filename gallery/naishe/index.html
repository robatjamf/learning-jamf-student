Block 4 — Webhooks

Push vs Pull

Polling = "Are we there yet?" every few seconds.
Pushing = "I'll ring your doorbell when someone arrives."

Update EA via API
↓

↓

Event-driven integration in action.

API Token Lifecycle

Authenticate → Work → Invalidate

Always follow this pattern — treat tokens like temporary badges, not permanent keys.

# Step 1 — Get token POST /api/v1/auth/token # Step 2 — Do your work GET /api/v1/computers-inventory PUT /JSSResource/computers/id/:id # Step 3 — Invalidate when done POST /api/v1/auth/invalidate-token

Like logging out after a session. If someone finds your token in terminal history, it's already dead.

Day Three

AI-Native Development

Claude Code + the Compound Engineering loop.

The Framework

Plan

Define requirements. Gather context. Surface unknowns.

Work

Execute with AI. Stay within the plan.

Review

You evaluate first. Ask the agent for gaps.

Compound

Distil into COMPOUND.md. Next session inherits it.

Afrobeats runs on rhythm and call-and-response. So does compound engineering — each loop you call, the next one responds with more.

CLAUDE.md vs COMPOUND.md

CLAUDE.md

Lean project setup — structure, current state. Claude reads this first every session. Keep it short.

COMPOUND.md

Rich session history — decisions, tradeoffs, dead ends, discoveries. Context accumulates here.

Warning Signs — When to Quit
  • ✕ Solution keeps growing, harder to follow
  • ✕ Agent repeats itself or forgets details
  • ✕ "Actually, let's try..." keeps appearing
  • ✕ You can't explain what Claude is doing
  • ✕ Your gut says something is off

Restarting with better context is faster than pushing through a bad path.

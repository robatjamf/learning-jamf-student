Day 2 · Key Concepts

API

REST API

GET / POST / PUT / DELETE. JSON in, JSON out. Bearer token for auth — get it once, use it everywhere.

Auth

Bearer Token

POST to /api/v1/auth/token, get a token, attach it to every request. Invalidate when done.

Event

Webhook

A URL that listens. Instead of polling, Jamf calls YOU when something happens — enrollment, policy fail, check-in.

VM

Virtual Machine

A computer inside your computer. Safe sandbox. Tart runs macOS VMs on Apple Silicon — clone, run, test, reset.

Build

Packer

Write a template once, build the same VM image every time. Reproducible environments, no drift.

Format

JSON vs XML

Jamf Pro API uses JSON. Classic API uses XML. Extension Attributes live in the Classic API.

Day 2 · Commands Cheat Sheet

tart clone <source> <name> Copy a VM image

tart ip <name> Find VM's IP address
curl -X POST .../api/v1/auth/token Get a Bearer token

git checkout -b students/<name> Create your student branch

Day 3 · 7 Transferable Principles

01Context Is Everything▶
The quality of your output is determined by the quality of your context. Point the agent to relevant files, explain the why, share constraints upfront.
Ask a stranger to grab your jacket — they need to know where you live, what it looks like, and where you left it.
02Planning > Building▶
80% planning, 20% building. The plan IS the work. Execution is just confirmation. Ask the agent to explain its approach before it starts — poke holes in it.
Look at the blueprint before breaking ground.
03Share Your Mental Model▶
The agent starts from zero every time. "Here's how I'm thinking about this…" is the fastest path to good output. Transfer your picture of done.
04Recognize When to Quit▶
Sunk cost is a trap. If the solution is getting more complicated, the agent keeps changing approaches, or something feels off — stop. Starting fresh with better context is faster.
You took a wrong turn. Turn around now instead of driving further.
05It's a Conversation, Not a Command▶
You're collaborating, not delegating. Let the agent ask you questions. Ask it what could go wrong. Pair with it like a smart colleague who just joined the project.
06Review Against Your Plan▶
Open the output. Use it. Click the buttons. Your eyes and judgment are the primary review tool. Compare what's there to what you intended — then ask the agent to find gaps.
Taste the dish yourself before asking someone else for their opinion.
07Compound Your Sessions▶
Distill decisions, tradeoffs, dead ends, and reasoning into COMPOUND.md at the end of every session. The next session starts with all of that context instead of zero.
A pilot's logbook — not just "good flight" but the route, weather decisions, turbulence, what you'd do differently.

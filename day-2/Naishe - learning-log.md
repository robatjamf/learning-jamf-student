## After Block 4 — Webhooks

**Push vs pull — what is the difference in your own words?**

> In APIs, push and pull describe how data is shared between systems. Push is when a server automatically sends data to another system when an event happens. The receiving system does not need to ask for the data because it is sent right away.

Pull, on the other hand, is when a client requests data from the server when it needs it. The client sends a request to the API to get the information.

**What did the webhook payload look like when it arrived? What information was in it?**

>When the webhook payload arrived,i was excited because i found out it contained structured JSON data describing the event that triggered the webhook. This information allows the receiving system to understand what happened, when it happened, and which resource was affected.

>It makes perfect senses  for explaining APIs! It perfectly captures the idea that you don't need to know how the kitchen works; you just need to know how to read the menu. 
Client (You): The one asking.

API (The Waiter): The messenger. It takes your request, tells the system what to do, and brings the response back to you.

Server (The Kitchen): The system that does the actual work.

The API is the interface that allows two different systems to talk to each other without them needing to know how the other works.
